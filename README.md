# 개인 대시보드 (Streamlit)

대출·환율·재산세·연봉을 한 곳에서 보는 개인용 웹앱입니다.
PC 브라우저와 휴대폰 브라우저 모두에서 같은 화면으로 씁니다.

## 들어있는 프로그램

| 페이지 | 내용 |
|---|---|
| 🏦 대출 상환 계산기 | 고정→변동금리, 날짜 기준 중도상환, 중도상환수수료, 상환표 CSV |
| 💱 환전 타이밍 | USD·JPY·EUR·CNY·SGD — **1일 전·1주일 전** 단기 등락 + 3년/2년/1년/6개월/3개월/1개월 평균 대비 |
| 🏠 재산세·종부세 | 물건별 공시가격·지분 → 7월/9월 재산세 + 12월 종부세, 연도별 기록·예상 |
| 💰 연봉·급여 관리 | 연도별 계약연봉·월별 급여, 물가 대비 실질 인상률, 내년 권장 연봉 |
| 🥚 금리 사이클 | 코스톨라니 달걀 모형으로 보는 기준금리 위치와 국면별 자산 배분 |
| 🏷️ 양도세 계산기 | 보유기간·주택수로 예상 양도소득세, 세제개편안 비교 |
| 📊 자산배분 현황 | 주식·ETF·펀드·코인을 계좌별로 · 금리 국면과 대조 |
| 💎 순자산 | **내 몫 / 가족 몫 / 가구 합계**를 나눠서 · 전국 백분위 · 증감 속도 |
| 🧓 연금 | 국민연금·퇴직연금 예상 수령액 |
| 📥 자료 가져오기 | 예전 프로그램에서 저장한 JSON 파일 올리기 |
| ➕ 내 프로그램 | `myapps/` 에 넣은 내가 만든 계산기 |

### 💎 순자산 — 내 돈과 가족 돈 나누기

자산·부채를 **줄마다 소유자(본인 / 배우자 / 공동)** 로 넣습니다.
공동명의는 `내 지분(%)` 에 등기 지분율을 적으면 그만큼만 내 몫이 됩니다.

```
가구 = 모든 줄 전액              ← 전국 비교(가계금융복지조사)에 쓰는 값
개인 = 본인 전액 + 공동 지분분    ← 내 몫
가족 = 가구 − 개인               ← 배우자 전액 + 공동 나머지
```

부부 공동명의 집에 걸린 대출도 같은 지분으로 나뉘므로, 자산만 나누고
부채는 안 나누는 데서 오는 왜곡이 생기지 않습니다.
예전 버전(배우자 자산을 숫자 한 칸으로 받던 형식)으로 저장한 자료는
페이지를 열 때 이 표로 한 번 자동 변환됩니다.

## 처음 설정

```
pip install -r requirements.txt
```

비밀번호 설정 (필수):
1. `.streamlit/secrets.toml.example` 을 같은 폴더에 `.streamlit/secrets.toml` 로 복사
2. 안의 `password = "..."` 를 본인만 아는 비밀번호로 수정
3. 이 파일은 절대 공유하거나 git 에 올리지 마세요 (`.gitignore` 에 이미 포함)

## 실행

Windows: **`실행_윈도우.bat` 더블클릭**

또는 직접:
```
python launcher.py
```
브라우저 자동 실행을 원하지 않으면:
```
python launcher.py --nobrowser
```
Streamlit 을 직접 띄우려면:
```
streamlit run Home.py
```

> 시스템 ANSI 코드페이지(한국어 Windows = CP949)로 읽기 때문에 UTF-8 한글을
> 넣으면 글자가 깨지고 `for ... in ... do` 같은 구문까지 부서집니다.
> 한글 안내와 실제 작업(패키지 설치, 접속 주소 안내, 서버 실행)은 모두

브라우저가 자동으로 열립니다. 같은 와이파이의 휴대폰에서 보려면 터미널에

## 이번 버전에서 고친 것 (대출 계산기 중도상환)

### 1. 경과이자 이중 계상 ★가장 큰 오류
이전 버전은 중도상환 시점에 **전체 잔액**에 대한 일수 이자를 받고,
바로 다음 정기납입일에 **다시 한 달치 이자 전액**을 받았습니다.
같은 기간의 이자를 두 번 계산해서 총이자가 부풀려졌습니다.

실제 은행 명세서와 대조해 검증했습니다. 예를 들어 잔액 4억, 연 3.92% 대출에서
직전 납입일로부터 11일 뒤에 500만원을 중도상환한 경우:

| 계산 방식 | 경과이자 |
|---|---|
| 은행 실제 청구액 | 5,906원 |
| 이전 버전 (전체 잔액 기준) | 472,548원 |
| 수정 후 (중도상환 원금 기준) | 5,907원 |

같은 방식으로 서로 다른 4건을 대조했고 모두 1원 이내로 일치했습니다.

수정 후에는 **중도상환하는 원금분에 대해서만** 경과이자를 계산하고,
남은 잔액의 이자는 다음 정기납입일에 한 번만 받습니다.
경과일수는 **명목 약정일**(영업일로 밀리기 전 날짜)부터 셉니다.

옵션에서 **전체잔액 일수정산** 방식도 고를 수 있고, 이 경우 정기납입 이자를
실제 경과일수만큼만 계산해서 역시 이중 계상이 생기지 않습니다.

### 2. 첫납입일 이전 중도상환 시 이자가 음수
경과일이 음수로 계산되어 이자가 `-1,150,685원` 처럼 나왔습니다.
대출시작일부터 구간을 나눠 계산하도록 고쳤고, 표의 날짜 순서도 정상화했습니다.

### 3. 같은 날 중도상환 2건 이상일 때 두 번째 건 이자가 0
경과이자 기준일을 "직전 이자정산일"로 고정해서 각 건마다 정확히 계산합니다.

### 4. 중도상환일이 주말로 밀린 납입일과 겹칠 때 이자 누락
명목 약정일 ~ 실제 상환일 사이의 하루·이틀치 이자를 반영합니다.

### 5. 표에 입력한 중도상환 행이 중복되거나 사라지는 현상
`st.data_editor` 의 편집 내용을 매번 원본에 되쓰면서 편집 기록이 다시
덮여 생기던 문제입니다. 원본 자료를 고정하고 편집기가 돌려준 값만
계산에 쓰도록 구조를 바꿨습니다.

### 6. 원금균등 + 기간단축형에서 목표 상환회차가 갱신되지 않음

### 7. [기능 추가] 중도상환수수료
```
수수료 = 중도상환원금 × 수수료율(%) × 잔여면제기간일수 ÷ 전체면제기간일수
```
면제기간(기본 36개월)이 지나면 0원. 이자 절감액에서 수수료를 뺀
**순 효과**도 함께 표시합니다.

## 문제가 생길 때

**`실행_윈도우.bat` 을 실행했더니 한글이 깨지고 `'...'은(는) 내부 또는 외부 명령...` 오류가 뜬다**
→ `.bat` 파일에 한글이 들어간 경우입니다. 배치 파일은 반드시 ASCII 만 쓰세요.

**Python 을 못 찾는다고 나온다**
→ 파이썬 설치 시 `Add python.exe to PATH` 를 체크하지 않은 경우입니다.
   재설치하거나, 명령 프롬프트에서 `python launcher.py` 를 직접 실행해 보세요.

**휴대폰에서 접속이 안 된다 (같은 와이파이인데도)**
→ Windows 방화벽에서 Python 의 네트워크 접근을 허용해야 합니다.
   처음 실행할 때 뜨는 방화벽 창에서 `개인 네트워크` 를 체크하고 허용하세요.

**서버는 떴는데 브라우저가 안 열린다**
→ `launcher.py` 가 포트가 열릴 때까지 기다린 뒤 브라우저를 엽니다. 그래도 안 열리면
   주소창에 `http://localhost:8501` 을 직접 입력하세요.
   `.streamlit/config.toml` 에 `headless = true` 를 넣으면 브라우저가 열리지 않으니
   그 줄을 추가하지 마세요.

**`External URL: http://222.x.x.x:8501` 로 밖에서 접속이 안 된다**
→ Streamlit 이 표시하는 공인 IP 주소인데, 공유기 포트포워딩이 없으면 접속되지 않습니다.
   (그리고 포트포워딩은 https 가 아니라 권장하지 않습니다.)
   밖에서 쓰려면 `외부접속_설정_가이드.md` 의 세 가지 방법 중 하나를 쓰세요.

**패키지 설치가 실패한다**
→ 명령 프롬프트에서 아래를 직접 실행해 오류 메시지를 확인하세요.
```
python -m pip install -r requirements.txt
```

# 추가 기능 안내

## 화면 테마 (라이트 / 다크)

PC·휴대폰의 **시스템 다크모드 설정을 자동으로 따라갑니다.**
`.streamlit/config.toml` 의 `[theme]` 섹션을 비워두면 Streamlit 이 브라우저의
`prefers-color-scheme` 을 읽어서 알아서 맞춥니다.

직접 고르고 싶으면 앱 화면 **우측 상단 ⋮ → Settings → Appearance** 에서
`Use system setting` / `Light` / `Dark` 를 선택하세요.
현재 적용된 테마는 왼쪽 사이드바 아래쪽에 표시됩니다.

> **주의** — `[theme]` 에 `base` 나 색을 지정하면 그 순간 "커스텀 테마"가 되어
> 라이트로 고정되고 시스템 설정을 따라가지 않습니다.
> 마찬가지로 `[client] toolbarMode = "minimal"` 을 넣으면 위 메뉴가 사라져서
> 테마를 직접 바꿀 수 없습니다. 두 항목 모두 일부러 비워두었습니다.

내가 만든 화면도 자동으로 라이트/다크에 맞게 그려집니다.
`ui.카드()` 같은 함수가 색을 직접 쓰지 않고 반투명 회색(`color-mix`)을 쓰기 때문입니다.
직접 CSS 를 넣을 때도 `#ffffff` 같은 고정 색보다 `rgba(127,127,127,.08)` 이나
`currentColor` 를 쓰면 두 테마에서 모두 자연스럽습니다.

## 내가 만든 프로그램 추가하기

두 가지 방법이 있습니다. 대부분은 **1번**이 편합니다.

### 방법 1 — `myapps/` 폴더 (간단, 권장)

`myapps/` 폴더에 아무 이름으로 `.py` 파일을 만들고 `실행()` 함수만 쓰면 됩니다.
화면 보일러플레이트가 전혀 없고, 파일 이름에 번호나 이모지를 붙이지 않아도 됩니다.

```python
# myapps/내_계산기.py
제목 = "내 계산기"        # 없으면 파일 이름을 씁니다
아이콘 = "🧮"             # 없으면 🧩
설명 = "간단한 계산"        # 없어도 됩니다


def 실행():               # ← 이 함수만 있으면 됩니다
    import streamlit as st
    from app_kit import 원, 카드_줄, 저장, 불러오기

    값 = st.number_input("숫자", value=10)
    카드_줄([("두 배", 원(값 * 2))], 열수=1)

    if st.button("저장"):
        저장("내계산기", {"값": 값})       # data/내계산기.json 에 저장됩니다
```

저장하고 **➕ 내 프로그램** 페이지에서 왼쪽 **🔄 내 프로그램 다시 읽기** 를 누르면
바로 나타납니다. 서버를 다시 시작할 필요가 없습니다.

- 동작하는 예제: `myapps/예제_적금_계산기.py`
- 파일 이름이 `_` 나 `.` 으로 시작하면 무시됩니다 (작업 중인 파일 숨기기용)
- 파일에 오류가 있어도 다른 프로그램은 정상 동작하고, 오류 내용이 화면에 표시됩니다

### 방법 2 — `pages/` 폴더 (독립 페이지)

왼쪽 메뉴에 별도 항목으로 넣고 싶을 때 씁니다.
`pages/_템플릿.py.txt` 를 복사해서 `pages/5_🚗_자동차_유지비.py` 처럼 저장하세요.
파일 앞의 숫자가 메뉴 순서입니다.

```python
import os, sys
sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
from app_kit import *

시작("자동차 유지비", "🚗", "연비로 월 유지비 계산")   # 로그인·모바일·제목 한 줄 처리

# ---- 여기서부터 자유롭게 ----
거리 = st.number_input("월 주행거리(km)", value=1200)
카드_줄([("월 유류비", 원(거리 / 12 * 1700))], 열수=1)
```

### `app_kit` 에서 쓸 수 있는 것들

| 이름 | 설명 |
|---|---|
| `시작(제목, 아이콘, 부제)` | 로그인 확인 + 모바일 CSS + 로그아웃 버튼 + 제목 (pages/ 전용) |
| `원(값)` `만원(값)` `억(값)` | 금액 문자열 (`1,234,000원` / `123만원` / `1.23억원`) |
| `카드(제목, 값, 부제)` `카드_줄([...], 열수)` | 테마 대응 요약 카드 |
| `저장(키, 값)` `불러오기(키, 기본값)` | `data/키.json` 에 JSON 저장·읽기 |
| `백업_사이드바(키, 값, 파일명)` | 사이드바에 백업 내려받기/복원 UI |
| `날짜로(값)` | 어떤 형태든 `datetime.date` 로. 못 읽으면 `None` |
| `숫자로(값)` `정수로(값)` | 콤마·'원' 섞인 값도 숫자로 |
| `표만들기(자료, 열정의)` | `st.data_editor` 용 DataFrame 을 안전한 dtype 으로 생성 |

### 표(st.data_editor)에 날짜 열을 넣을 때 — 반드시 `표만들기()` 사용

```python
df = 표만들기(자료목록, {"날짜": "date", "금액": "number", "메모": "text"})
결과 = st.data_editor(df, column_config={"날짜": st.column_config.DateColumn()})
```

날짜 열을 `pd.to_datetime()` 으로 `datetime64` 로 만들면 **pandas 3.x 에서
편집한 날짜가 반영되지 않습니다.** `DateColumn` 이 돌려주는 `datetime.date` 를
`datetime64` 열에 넣을 때 pandas 가 `TypeError` 를 내기 때문입니다.
`표만들기()` 는 날짜 열을 `object` dtype 으로 유지해서 이 문제를 피합니다.

## 이번 버전에서 고친 것 (중도상환 날짜)

**날짜(연도)를 바꿔도 표에 반영되지 않던 문제**
`pd.to_datetime()` 으로 날짜 열을 `datetime64[us]` 로 만들어 두었는데,
pandas 3.x 에서는 이 열에 `datetime.date` 값을 넣으면
`TypeError: Invalid value ... for dtype 'datetime64[us]'` 가 발생합니다.
Streamlit 의 `DateColumn` 은 정확히 그 `datetime.date` 를 돌려주므로,
달력에서 날짜를 고쳐도 pandas 가 거부해서 입력이 사라졌습니다.
→ 날짜 열을 `object` dtype (`datetime.date` 보관) 으로 바꿔 해결했습니다.

**잘못된 날짜가 조용히 무시되던 문제**
예전에는 날짜를 못 읽으면 그 줄을 말없이 건너뛰어서, 계산에서 빠진 것을
알 수 없었습니다. 이제는 아래처럼 이유를 화면에 알려주고,
계산에 반영될 목록도 표 아래에 함께 보여줍니다.

- `2026` 처럼 연도만 넣은 경우 → 1월 1일로 바뀌지 않고 경고 표시
- `26-05-20` 처럼 두 자리 연도 → 2020-05-26 으로 오해되지 않고 경고 표시
- 1990~2100년 밖의 연도 → 경고 표시
- 대출시작일보다 앞선 날짜 → 계산하기를 누르기 전에 미리 경고


## 예전에 저장한 자료 올리기

**📥 자료 가져오기** 페이지에서 예전 프로그램이 만든 JSON 파일을 그대로 올리면
형식을 알아보고 알맞은 곳으로 넣어줍니다. 여러 개를 한 번에 올려도 됩니다.

| 올릴 수 있는 파일 | 어디서 만든 것 | 들어갈 곳 |
|---|---|---|
| `salary_data.json` | 예전 연봉 관리 (tkinter) | 💰 연봉·급여 관리 |
| `property_tax_settings.json` | 예전 재산세 계산기 (입력값) | 🏠 재산세·종부세 |
| `property_tax_history.json` | 예전 재산세 계산기 (연도별 기록) | 🏠 재산세·종부세 |
| `대출계산기_설정.json` | 대출 계산기 (구/신 버전) | 🏦 대출 상환 계산기 |
| `연봉자료_백업_2026-07-31.json` 등 | 이 대시보드의 백업 | 원래 자리 |

- **파일 이름은 달라도 됩니다.** 내용을 보고 판별합니다.
- 올리면 먼저 **무엇이 들어있는지** (몇 개 연도, 몇 건 등) 보여주고,
  **가져오기 실행** 을 눌러야 실제로 반영됩니다.
- 연봉 자료는 **덮어쓰기 / 건너뛰기** 를 고를 수 있습니다.
  이미 2020년 자료가 있는데 파일에도 2020년이 있으면 어느 쪽을 남길지 선택합니다.
- 아주 옛날 형식(`base` / `allowance` / `net` 키)의 급여 자료도 읽습니다.
- 구버전 대출 설정의 `이자(직접입력, 선택)` 키와 `NaN` 값도 자동으로 정리합니다.

예전 프로그램 파일은 보통 그 프로그램의 `.py` 파일과 같은 폴더에 있습니다.

## 이번 버전에서 고친 것 (연봉 관리)

**2026년 자료만 입력되던 문제**
연도 선택 드롭다운이 **사이드바에만** 있었고 `key` 없이 `index` 로만 기본값을
지정했습니다. 이 경우 두 가지 문제가 생깁니다.

1. Streamlit 은 `key` 없는 위젯을 **매개변수 조합으로 식별**합니다.
   자료가 늘어나 `index` 계산 결과가 바뀌면 다른 위젯으로 인식해서
   선택이 기본값으로 되돌아갑니다.
2. 휴대폰에서는 사이드바가 접혀 있어서 연도를 바꿀 방법이 화면에 보이지 않았습니다.

→ 연도 선택을 **화면 맨 위 본문**으로 옮기고 `key="급여_연도"` 로 고정했습니다.
   ◀ ▶ 버튼으로 한 해씩 이동할 수 있고, 자료가 있는 연도에는 ✓ 표시가 붙습니다.
   2010~2035년 어느 연도든 선택·저장되는 것을 테스트로 확인했습니다.

**연봉·재산세 페이지에서 가끔 `KeyError: '급여_표버전'` 이 나던 문제**
`if "급여_자료" not in session_state:` 블록 **안에서** 표버전을 만들고 있어서,
다른 페이지(자료 가져오기 등)가 자료만 먼저 넣어준 경우 표버전이 없었습니다.
→ 두 키를 각각 `setdefault` 로 초기화하도록 바꿨습니다.

**f-string 안에 같은 따옴표를 중첩해서 Python 3.11 이하에서 실행되지 않던 문제**
`f"...{st.session_state["키"]}"` 형태는 Python 3.12 이상에서만 허용됩니다(PEP 701).
→ 안쪽을 작은따옴표로 바꿔 3.9 이상 어디서나 동작합니다.

# 자료 저장 위치

앱은 두 가지 방식 중 하나로 자료를 저장합니다. 설정에 따라 **자동으로** 골라집니다.

| 방식 | 언제 쓰이나 | 저장 위치 |
|---|---|---|
| 로컬 파일 | 기본 | 앱 폴더의 `data/*.json` |
| GitHub 비공개 Gist | secrets 에 `github_token` + `gist_id` 가 있을 때 | 내 GitHub 의 secret Gist |

현재 어느 쪽인지는 **왼쪽 사이드바 → 저장 위치**에서 확인할 수 있습니다.

## 왜 Gist 인가

Streamlit Cloud 는 서버가 재시작되면 파일이 초기화됩니다. 연봉 기록처럼
쌓아가는 자료가 사라지면 곤란하므로 바깥 저장소가 필요합니다.

- 어차피 Streamlit Cloud 때문에 GitHub 계정은 필요함 → 토큰 하나만 더 발급
- 저장할 때마다 **자동으로 이력**이 남아 실수로 덮어써도 되돌릴 수 있음
- 앱 코드와 **같은 저장소**에 자료를 커밋하면 Streamlit Cloud 가 변경을 감지해
  앱을 재시작합니다. Gist 는 별개라서 이 문제가 없습니다
- 토큰 권한이 `gist` 하나뿐이라 유출돼도 피해 범위가 좁습니다

설정 방법은 `외부접속_설정_가이드.md` 의 **[2단계]** 를 보세요.

## 동작 방식

- **읽기** — Gist 전체를 세션당 한 번만 받아옵니다. 한 번의 API 호출로
  모든 프로그램의 자료가 함께 옵니다. 5분이 지나면 다시 읽습니다.
- **쓰기** — Gist 에 저장하면서 로컬에도 사본을 남깁니다.
- **실패 시** — GitHub 이 응답하지 않으면 로컬 사본으로 계속 동작하고,
  화면에 원인을 표시합니다. 앱이 멈추지 않습니다.
- **여러 기기** — PC 와 휴대폰이 같은 Gist 를 봅니다. 한쪽에서 저장한 걸
  바로 보려면 사이드바 **저장 위치 → 다른 기기의 변경 내용 가져오기**.

## 내가 만든 프로그램에서 쓰기

`myapps/` 나 `pages/` 에 추가한 프로그램도 그대로 쓸 수 있습니다.
저장 방식은 알아서 정해지므로 신경 쓸 필요가 없습니다.


# 🥚 금리 사이클 (달걀 모형)

코스톨라니 달걀 모형으로 현재 기준금리가 사이클의 어디쯤인지 보여줍니다.

## 데이터

| 상황 | 동작 |
|---|---|
| API 키 있음 | 한국은행 ECOS / FRED 에서 자동 조회 (6시간 캐시) |
| 키 없음 | 내장 기본 이력 사용 + 화면에서 직접 추가 |
| 직접 입력 | 설정에서 현재 금리를 지정하면 그 값 우선 |

API 키는 선택입니다. 없어도 **설정 → 금리 변경 이력 추가**에서 새 금리 결정이
나올 때마다 한 줄씩 넣으면 그대로 동작합니다.

키를 쓰려면 비밀번호와 같은 곳(`secrets`)에 넣습니다.

```toml
ecos_api_key = "한국은행 ECOS 키"     # https://ecos.bok.or.kr/api/
fred_api_key = "FRED 키"              # https://fred.stlouisfed.org/docs/api/api_key.html
```

## 사이클 밴드

현재 위치(0~100%)는 `(현재금리 - 저점) / (고점 - 저점)` 으로 계산합니다.
저점·고점을 비워두면 최근 3년 이력에서 자동으로 찾고, 직접 지정할 수도 있습니다.
시장이 예상하는 **최종금리**를 고점에 넣으면 위치가 더 현실에 가깝게 나옵니다.

## 원본에서 바꾼 것

업로드해 주신 `egg_cycle.py` 의 계산 로직은 그대로입니다.
국면 판정과 각도 계산을 r 0~1 구간에서 202개 지점 전수 대조해 일치를 확인했습니다.

바꾼 것은 두 가지입니다.

**1. 차트를 matplotlib → plotly 로**
Streamlit Cloud 리눅스 서버에는 한글 폰트가 설치되어 있지 않습니다.
matplotlib 로 그리면 "금리정점" 같은 글자가 전부 네모(□□□)로 나옵니다.
plotly 는 브라우저가 글자를 그리므로 이 문제가 없고, 다크모드에도 맞춰집니다.

**2. 파일 캐시 → Streamlit 캐시**
`DailyCache` 가 쓰던 `.egg_cycle_KR.json` 파일은 클라우드에서 재시작 시
사라집니다. `st.cache_data(ttl=6시간)` 으로 바꿔서 환경과 무관하게 동작합니다.

`requests` 의존도 표준 라이브러리(`urllib`)로 바꿔서 설치할 패키지를 줄였습니다.
